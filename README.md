# Website

The public website, https://marbledropdaily.github.io: the home page, the privacy policy and the
terms. Google needs the first two to let the upload permission (OAuth) be "In production", and the
YouTube API rules ask for the privacy policy.

It is plain static HTML. To publish a change, upload the changed files to the GitHub repository
`marbledropdaily/marbledropdaily.github.io` (GitHub Pages serves it from `main`).

If what the bot stores changes (`bot/store.py`), update `privacy.html` and its date.
